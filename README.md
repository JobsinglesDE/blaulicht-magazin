# Blaulichtsingles Magazin

Redaktionelles Online-Magazin von **Blaulichtsingles** – der Dating-Plattform für Polizei, Feuerwehr, Sanität und Rettungsdienst in der Schweiz. TV-News, Promi-Ärzte- und Schauspieler-Porträts sowie Partnersuche-Tipps („Bekanntschaften") für Blaulicht-Berufe.

Gebaut mit [Next.js](https://nextjs.org/) und [Keystatic](https://keystatic.com/), deployed auf [Vercel](https://vercel.com/).
